# GitHistorian 🗺️

An interactive spatial map of your codebase where Git history comes alive. Visualize branches, track change magnitude, and explore temporal evolution—all layered directly onto your architecture.

## Features ✨

- **Spatial Visualization** - Navigate your codebase as an interactive map
- **Git History Integration** - Every commit, branch, and change visible in time and space
- **Change Magnitude Layers** - See at a glance which parts of your code are being modified most
- **Temporal Analysis** - Watch how your architecture evolves over time
- **Branch Topology** - Explore parallel development and merge patterns
- **Interactive Exploration** - Zoom, pan, and drill down into specific files and commits
- **See Interaction Flows** - View dependencies and imports in your project evolve over time (Currently only JS based languages and Python are supported)

## Quick Start

```bash
npm install
npm run dev
```

Or you can run it in a docker container:
```bash
docker compose up
```

## Project Structure

GitHistorian maps your git repository into an interactive spatial interface, combining:
- 📁 Code architecture
- 🌳 Git branch structure
- 📊 Change frequency & magnitude
- ⏰ Temporal commit history
